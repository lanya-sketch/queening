## 2. 남은 작업 전수 (목록만, 미수정)

### 2-1. 바이블(M2b-0)에 설계돼 있으나 미구현

- **★ 시작 기질 선택** (`M2b-0:317`) — "M3 엔딩 이후 마무리 단계"로 예약. 시작 스탯/자원 프리셋(영민/강건/영악/여린), 트레이드오프 ±5~10, "난이도" 아닌 "어떤 아이였는가" 서사 프레이밍. **방금 만든 이름·성별 선택 인트로에 자연히 얹히는 다음 조각.** 유년기(#26)처럼 "설계는 완성, 구현만 남음".
- **동양판 이식 / 성별 대비 개방** (`M2b-0:56,0-6`) — 텍스트 중앙화가 선행 조건(로드맵 지속 언급). 큰 라운드.

### 2-2. M3-pending 예약 중 미구현

- **★ 모후의 약 — 중반 전개** (`M3-pending #3`) — `queen_poison_path` flag는 심어졌고 **엔딩 판정은 회수됨**(배드:꼭두각시). 그러나 "실제 약 시도 전개 이벤트 + 막을 기회"라는 **중반 플레이는 미구현.** 재기 여지를 남기는 성질 유지가 조건.
- **섭정 관계 미결** (`M3-pending #6`) — `regent_alliance` + 높은 의심 공존 시 엔딩 처리 미정.
- 그 외 대부분(공동왕조·군사노선·혈서·두루마리·민심 flag)은 엔딩에서 회수 완료.

### 2-3. 부분 구현 (설계는 있고 일부만)

- **청산 후일담 구간** (`reckoning.ts:14,191`) — ⑤만 3구간(낮음/중간/높음) 전부, **①②④는 높은 구간만.** 중간·낮음 후속 확장 예약.
- **조기 데드엔딩** (`deadends.ts:9`) — 현재 대표 2종(심신파탄·의심무방비). 나머지 확장 예약(구조는 열림).

### 2-4. 에셋 플레이스홀더

- **배경 에셋** (`ScenePlayer.tsx:95`) — 씬 배경은 아직 "어두운 기본" 위 전신 스프라이트만. 배경 그림 후속.

### 2-5. 텍스트 플레이스홀더 — **없음(정본은 완결)**

- `skeletons.ts:10-11` 주석은 "5 tier 플레이스홀더"라 쓰였으나 **스테일** — M3-2b에서 여덟 골격 전부 실제 텍스트로 채워졌고 catch-all만 범용 안전망(1만 세이브 0건). 주석만 낡음.

### 2-6. 밸런스 정밀 조정 (예약)

## 3. 16~20세 콘텐츠 밀도

### 3-1. 무엇이 있는가 (메인 루프)

| 나이(연차) | 마일스톤·서사 | 미스터리 | 로맨스·장치 | 정치 현안 |
|---|---|---|---|---|
| 16 (5년) | 외가의 추도식, 데뷔탕트(m9) | 침실 수색/실마리, 半혈서 | 데뷔탕트 로맨스 개방 | **하원(m6) ← 마지막** |
| 17 (6년) | 성년식, 왕대비궁 약재 | 진실 사슬 | 영웅 입궁(m10), 정복, 공동왕조, 결정적 씬 | **없음** |
| 18 (7년) | 담판, 결렬 | 깊은 진실 | 두루마리, 군사노선 | **없음** |
| 19 (8년) | — | — | 처분, 청산 ×4 | **없음** |
| 20 (9년) | 엔딩·후일담 | — | — | **없음** |

상시 층: 일상 소소 풀 28종(대부분 나이 무관/13~14세 조건이라 16~20에도 뜸) + ③ 방문 사이클 + **계절 이벤트 4종(신규)**.

### 3-2. 두 개의 실제 공백

1. **★ 정치 현안이 16세에서 끊긴다.** state_affair는 총 3개(변경 13세 / 제국 15세 / 하원 16세)뿐이고 **17~20세에 새 현안이 0.** 후반은 마일스톤·로맨스·엔딩으로만 굴러가고, "왕으로서 나라를 다스리는" 정치 판단이 후반에 사라진다. — 로드맵의 미착수 "현안 2개 추가"가 정확히 이 구멍.
2. **★ 16+ 이벤트가 달에 분산되지 않는다.** 17~20세 이벤트 대부분이 `minAge`만 있고 `month`가 없어 **나이 오르는 1월에 몰린다.** 11~15세는 이번에 캐릭터별 유니크 월로 촘촘히 흩었는데, 후반은 그 작업이 안 돼 있다(달지정: 데뷔탕트 m9, 영웅 m10, 하원 m6 정도뿐).

### 3-3. 판단 — **후반 채우기 라운드 필요**, 단 성격이 다르다

11~15세는 "사람이 안 나온다"(등장 공백)를 채웠다. 16~20세는 **등장·로맨스·엔딩은 충분**하고, 빠진 건 **① 통치 현안, ② 달 분산**이다. 권장 범위:

- **(a) 17·18·19세 정치 현안 2~3개** — 제국 압박 심화 / 선왕 정책 잔재 / 하원 후속. 위임 균형(의심 −4) 조정 동반. *(로드맵 기존 계획 실행)*
- **(b) 기존 16+ 마일스톤에 month 배정** — 성년식·담판·결렬 등을 서로 다른 달로 흩어 1월 클러스터 해소.
- **(c) 선택: 데뷔탕트~결정적 씬 사이 관계 심화 비트** — 로맨스가 지금 "데뷔탕트(개방) → 70 결정적 씬"으로 점프. 그 사이를 teen bonds처럼 얇게 채우면 낙차가 매끈해짐.

11~15세만큼 대규모는 아님 — (a)+(b)가 핵심, (c)는 선택.

## 4. 라이브 키 테스트 준비 상태

두 스크립트 모두 **키 없이도 sweep에서 정상**(가드되어 안내 후 exit 0). 라이브(키 투입) 실행 시:

| 스크립트 | 무엇을 재나 | 명령 | 상태 |
|---|---|---|---|
| `verify:chars` | 5인 목소리 분화(시트대로 다르게 말하는가) | `QUEENING_LIVE_KEY=sk-ant-... npm run verify:chars` | 셀렉터 최신(보내기·대화 dialog). **정상** |
| `verify:live-affection` | 회당 호감도 상승 실측 → 70 도달 회수 | `QUEENING_LIVE_KEY=sk-ant-... npm run verify:live-affection` | 측정은 정상(state.affection). **단 진단 셀렉터 낡음** |

### 4-1. ★ 발견된 소규모 회귀 (live-affection)

`live-affection.mjs:118`이 회차별 응답 미리보기를 `div.border-amber-900/50`로 읽는데, **리디자인 후 TalkModal 버블 클래스가 `border border-line-gold/50 bg-ink-900/60`로 바뀌어** 이 셀렉터는 0건 매칭 → 미리보기 줄이 **빈칸**으로 출력됨. 호감도 수치 측정 자체는 `state.affection`에서 읽어 **무손상**. 로그 진단만 손상.
→ 다음 코드 라운드에서 셀렉터 한 줄 교체 권장(측정 결과엔 영향 없음).

### 4-2. 준비물 / 예상 비용

- **키 형식**: `sk-ant-...` (Anthropic). `QUEENING_LIVE_MODEL`로 모델 지정 가능(기본값 사용 시 최신 Claude).
- **verify:chars**: 5인 × 소수 왕복. 환경변수로 라운드 조절.
- **verify:live-affection**: 기본 12회 왕복(`QUEENING_LIVE_ROUNDS`), `QUEENING_LIVE_CHAR`(기본 prince). **회당 1 API 호출 = 실제 과금.** 12회면 소액.
- 예측(M3-pending 계산): 호감도 5→70 = 65점, 회당 상한 +3 → 최소 22회 응답 필요. 실측 평균이 낮으면 세션 상한(60)에 먼저 걸릴 수 있음 → MAX_AFFECTION 또는 화제 보상(+8) 조정 후보. **이건 상한 계산이지 실측이 아니라서** 라이브 실행이 유일한 확정 수단.
